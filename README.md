# Center / 圆心

A location-aware social commerce platform using a map-first search experience.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Concepts: Location search, content publishing, merchant ordering

## Features in progress
- User auth and role system
- Public feed and merchant feed
- Map-first discovery with radius search
- Geo-aware content publishing
- Order flow for merchant services

## Quick start
```bash
npm install
npm install --workspace backend
npm install --workspace frontend
npm run dev
```

## Notes
This is a private prototype and intentionally designed for further iteration as a location-first social commerce product.
